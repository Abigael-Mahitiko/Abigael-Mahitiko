## 🚀 Projet à découvrir

### Espace personnel avec connexion Google

Une petite interface web en français qui propose une page de connexion Google et un espace d’accueil personnalisé. Ce projet m’a permis de travailler la mise en page responsive, les interactions JavaScript et l’intégration de Google Identity Services.

- [`index.html`](./index.html) — écran de connexion
- [`accueil.html`](./accueil.html) — espace personnel après connexion

> **Note :** il s’agit d’une démonstration front-end. Pour une authentification destinée à la production, le jeton Google doit également être vérifié côté serveur.
